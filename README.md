# SkyLink Telecom Customer Churn Prediction

## Project Overview

SkyLink Telecom is a fictional telecommunications company experiencing increasing customer churn.

The objective of this project is to build an end-to-end data science solution that predicts customer churn, identifies the primary factors contributing to customer attrition, and provides actionable business recommendations to improve customer retention.

This project demonstrates the complete machine learning lifecycle, including:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Statistical Analysis
- Machine Learning
- Model Evaluation
- Business Intelligence Dashboarding
